# MLP-Mixer 在 CIFAR-100 上的图像分类实验报告

## 1. 实验目的

实现并训练一种区别于传统 CNN/RNN 的现代深度学习模型，理解 MLP-Mixer 的 Token Mixing 与 Channel Mixing 机制，并在 CIFAR-100 上完成图像分类。

## 2. 数据集

CIFAR-100 包含 100 个类别的 32x32 RGB 图像。训练集划分为训练集和验证集，官方测试集用于最终评价。

## 3. 模型原理

MLP-Mixer 将图像划分为不重叠 patch，并映射为 token。每个 Mixer Block 由 Token-Mixing MLP 和 Channel-Mixing MLP 构成，并使用 LayerNorm 与残差连接。

### 3.1 Token Mixing
在 token 维度进行信息交互，使不同图像 patch 之间交换信息。

### 3.2 Channel Mixing
在通道维度进行非线性变换，学习每个 token 的特征表示。

### 3.3 与 ViT 的区别
本项目不使用 self-attention，因此不能把它简单理解为缩小版 ViT。其核心信息混合机制是 MLP。
